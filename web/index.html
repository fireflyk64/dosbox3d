Lobby: find pilots to fly with

A public chat room (WC-LOBBY; when it is full, WC-LOBBY0, WC-LOBBY1 and so on) where pilots say which room they fly in; a room code in a line can be clicked to join it. Entering connects your browser directly to the other pilots there, as a game does.

2. Room

Controller buttons and axes

The controller is the game's mouse and keyboard: the sticks steer (left stick turns and pitches, right stick pitches and rolls), the buttons press the game's keys. In menus and the barracks the left stick moves the pointer and the Fire guns button clicks. Each browser window has its own controller, so two windows side by side make a split screen: one controller each, or a controller in one and the keyboard and mouse in the other.

    Everyone who opens this page's link lands in this room. The first pilot in is the host and starts the game for everyone.

    3. Fly

    Load the game files and join a room first.

    Click the screen to give it the keyboard. Caps Lock is the game's Esc (it skips cutscenes), because the browser keeps Esc for leaving full screen; in Chrome and Edge a short tap of Esc also reaches the game in full screen, and holding it leaves. Press 0 to type a chat message to the other pilots, Enter sends it; in space Enter fires missiles. With voice on push to talk, hold ` (or the left stick's button on a controller) to speak. Ctrl+F10 releases the mouse.

    Save games

    Saving in a bunk writes the game's save file, which holds all eight bunks. This browser keeps a copy of it and puts it back the next time you play here; the download is your own backup, and can be restored in another browser.
